## Descripción del proyecto

Este proyecto consiste en un programa sencillo desarrollado en Python que permite verificar si una contraseña cumple con algunos requisitos básicos de seguridad. El programa comprueba que la contraseña tenga al menos 8 caracteres, una letra mayúscula y un número. Si cumple con estas condiciones, muestra que la contraseña es segura. De lo contrario, indica que es débil.

## ¿Cómo funciona?

El programa solicita al usuario que introduzca una contraseña. Luego recorre cada carácter utilizando un ciclo for para comprobar si contiene una letra mayúscula y un número. Finalmente, mediante una condicional if, verifica todas las condiciones y muestra el resultado.
